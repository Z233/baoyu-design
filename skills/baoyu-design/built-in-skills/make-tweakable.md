---
Make sure your design supports Tweaks. If the user tells you what to make tweakable, do that. Otherwise pick a few shared high-impact values — a system color/spacing scale, layout/density variant or behavior switch. Keep copy directly editable; expose copy controls only when requested. Use a local Show/Hide toggle, keep the panel compact and separate from product content, and hide it completely when off or exporting. Do not rely on a host message or editor panel. See [Portable design craft](../references/design-craft.md).
