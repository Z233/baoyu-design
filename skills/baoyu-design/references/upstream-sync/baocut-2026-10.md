## Directly portable, adapted, excluded

**Directly portable:** system/context priority; exact values and copied assets; restrained role-based typography; no filler/fabricated proof; flex/grid gaps; semantic controls and contrast; stable choices and fair tradeoffs; current-file focused edits; source inventory and honest gaps.

**Adapted:** real system components → `window.<Namespace>` with local providers; installed system → local importer/runtime closure; board exploration → `design-canvas.jsx` or variant controls; prototype links → standard anchors/state; design knobs → local hideable Tweaks panel; system tokens → existing CSS source; cover → ordinary card; feedback → actual harness DOM context.

**BaoCut-only exclusions:**

- `canvas.json`, `design-system.json`, their markers/limits, `launch`, `boards`, `notes`, `is_interactive`, Theme/Play/editor cards and special Cover semantics.
- `.dc.html`/`<x-dc>`/`DCLogic`/`<helmet>`/`<sc-for>`/`<sc-if>`/`<dc-import>`/`<x-import>` as a universal runtime. Existing custom-runtime artifacts remain supported only when that runtime is actually present.
- `design_check`, `design_import_asset`, `design_system_check`, `design_system_import_asset`, `space_list`, `skills_read`, reserved `assets/`/`_blobs/`, `/_blob/<id>` and upload ownership. Local copying and Node scripts remain the equivalents.
- Session annotations and opaque locator IDs, editor direct-manipulation guarantees, auto-generated API/manifest/token files, file-table state, make.ts recipes and editor source trust/sandbox claims.
- Blanket prohibition on shell/file rereads/browser/screenshot verification; blanket no-commit draft rule; BaoCut's lack of Send-to export; email/employment proxy for reproduction rights; mandatory subagent work. Local harness/project instructions and existing licensed-asset/export flows remain in force.

No changes to deck/video/animation starters, PPTX/PDF engines, Figma decoder, source importer implementations, asset store, or tweaks runtime/protocol. The PDF guidance only gates an existing custom-template runtime; the export itself is preserved.

## Repeatable checks

Run from the repo root:

```bash
npm run check:skill
npm test
git diff --check
```

`check-skill.mjs` checks active skill/built-in/reference Markdown links and rejects the six BaoCut-only tool names above. It skips fenced/inline **link examples**, but still scans tool names in code. Historical snapshots and this provenance directory are excluded from operational checks; links **to** their existing files still resolve. CLI tests use temporary fixture documents as input, not assertions against implementation source.

These checks prove package/reference integrity and existing local script behavior, not that every future model will follow the prompt or produce better visuals. No new product prototype or editor runtime is claimed as tested by this sync.

The completed run is recorded in [baocut-2026-10-checks.json](baocut-2026-10-checks.json), including command results and input/log hashes. Rerun the commands above to reproduce the checks.
